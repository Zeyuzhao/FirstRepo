# FirstRepo

This repository contains a Next.js app scaffolded with the App Router,
TypeScript, ESLint, and a live SQLite dashboard.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```

The dashboard creates a local SQLite database at
`.data/firstrepo-dashboard.sqlite`. The file is ignored by git and is seeded
automatically on first run.
